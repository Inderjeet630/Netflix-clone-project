# Netflix Clone 🎬

A responsive front-end clone of the Netflix home/landing page layout, built to practice semantic web design and clean styling.

## 🚀 Features
* Clean, semantic **HTML5** structure.
* Modern **CSS3** layout techniques (Flexbox & Grid).
* Responsive design across desktop, tablet, and mobile screens.
* Custom-styled buttons, input forms, and dropdowns.

## 🛠️ Tech Stack
* HTML5
* CSS3
